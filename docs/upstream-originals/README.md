# Upstream originals

Reference copies of the two upstream projects this app was originally built
from, saved here for provenance — what this app looked like at the source,
before any of this project's own fixes, redesigns, or migrations.

- `DELTA-GREEN-STATS-README.md` — the character creation/live play tool
  itself (`stats/` in this repo). Fetched from
  https://github.com/pigeon-labs-stack/DELTA-GREEN-STATS (`main` branch).
  Notably documents **six** visual themes at the source, before Modern
  (Catppuccin) and the separate Mobile theme were later retired here (see
  `FEATURES.md` and `BUGFIXES.md`).
- `delta-green-agent-wizard-module-README.md` — the Foundry VTT character
  creation wizard this project's own in-browser wizard was ported from.
  Fetched from
  https://github.com/pigeon-labs-stack/delta-green-agent-wizard-module
  (`master` branch).

Both are saved verbatim (as of the date fetched) and are not kept in sync
with upstream — they're a historical snapshot, not a live mirror.
