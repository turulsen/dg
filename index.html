Notes for Agents

  • Already have an Agent in this browser? The Continue Playing panel above jumps straight back to their Agent File — it only appears once you've exported or submitted at least one Agent here.
  • Start with the Character Creator if you're building a new Agent — it auto-saves as you go, so it picks back up where you left off in this browser. When ready, use its Export to Agent File button to send your Agent to the Portal.
  • The Character Creator's auto-save and the Agent Portal's Character Code (e.g. BRAD-K7X2) are two separate save systems — export from the Creator to the Portal when you want a printable dossier and cover ID, and keep your Character Code somewhere safe if you switch devices.
  • All defaults follow the Delta Green Agent's Handbook — check with your Handler if your table uses house rules.
