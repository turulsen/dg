Notes for Agents

  • Start with the Stat Generator if you're building a new character, then use your Character Code (e.g. BRAD-K7X2) to load your Agent into the Portal and ID Creator.
  • These tools save locally in your browser. Keep your Character Code somewhere safe if you switch devices.
  • All defaults follow the Delta Green Agent's Handbook — check with your Handler if your table uses house rules.
